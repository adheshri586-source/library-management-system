# Library Management System

JavaFX desktop library app built with Java 27 and Maven. The optional browser demo is in `library-app/LibraryManagementSystem/index.html`.

## Run the JavaFX app

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-27"
.\mvnw.cmd -f .\library-app\LibraryManagementSystem\pom.xml javafx:run
```
